# Movie Genre Classification

This project classifies movie plots into genres using a text classification pipeline.

## Goal

Predict the genre of a movie from its title and description.

## Model

- Text cleaning using regex
- TF-IDF vectorization
- Logistic Regression classifier

## Files

- `movie_genre_classification.ipynb` — main notebook
- `Genre Classification Dataset/train_data.txt` — source dataset

## Run

1. Open the notebook in Jupyter or VS Code.
2. Ensure the dataset is present in `../Genre Classification Dataset/train_data.txt`.
3. Run all cells in order.

## Expected Output

- Accuracy and classification report
- Confusion matrix
- Genre prediction examples for user input text
